## ✨ Features

- **🎨 Modern Design** with accent colors and smooth animations
- **📱 Fully Responsive** from 320px to 4K displays
- **♿ High Accessibility** (WCAG AA compliant)
- **⚡ Optimized Performance** with reduced motion support
- **🖱️ Interactive Hover Effects** with graceful degradation
- **🌙 Prefers-Reduced-Motion Support**
- **📝 Semantic HTML Structure**
- **🎯 Touch-Friendly Interface**

## 🎯 Technologies Used

- **HTML5** – Semantic markup
- **CSS3** – Flexbox, Grid, Custom Properties (CSS Variables)
- **Modern CSS** – `clamp()`, `min()`, `max()`, viewport units
- **Responsive Design** – Mobile First approach
- **Accessibility** – ARIA labels, keyboard navigation, skip links
- **Performance** – Reduced motion CSS, optimized images
- **Cross-Browser** – Compatible with all modern browsers
